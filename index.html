Đã đạt giới hạn API

Bạn đã vượt quá giới hạn sử dụng API. Vui lòng thử lại sau hoặc kiểm tra API key của bạn.

RPD (Requests Per Day) là số lượng yêu cầu bạn có thể thực hiện mỗi ngày với mô hình tương ứng. Giới hạn này được Google đặt ra dựa trên API key miễn phí.

TPM (Tokens Per Minute) là giới hạn tốc độ xử lý token mỗi phút. Giới hạn này áp dụng cho tổng số token được xử lý trong tất cả các request trong 1 phút.
