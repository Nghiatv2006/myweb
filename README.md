[README.md](https://github.com/user-attachments/files/24415690/README.md)# AI Chat Agent - Powered by Gemini 2.5

Chatbot AI thông minh với giao diện hiện đại, TTS giọng miền Bắc và hỗ trợ đa model Gemini.

## 🚀 Tính năng chính

### ✅ Chức năng bắt buộc
1. **Chat AI đa model**  
   Gemini 2.5 Flash Lite / Flash / Pro / Exp với streaming real-time

2. **Text-to-Speech (TTS)**  
   Nút **Đọc** với giọng Microsoft An (miền Bắc Hà Nội)

3. **Quản lý tin nhắn AI**
   - Tạo lại (Regenerate)
   - Sao chép (Copy)
   - Chỉnh sửa (Edit)

4. **Upload file**
   - Ảnh: PNG / JPG  
   - Tài liệu: PDF  
   - Upload trực tiếp trong khung chat

5. **Lưu trữ lịch sử**
   - Unlimited conversations
   - Lưu hoàn toàn bằng `localStorage`

---

### 🎯 Chức năng nâng cao
1. **Context Summarization**  
   Tự động tóm tắt khi vượt quá 50 tin nhắn

2. **Code Syntax Highlight**
   - Hỗ trợ hơn 50 ngôn ngữ lập trình
   - Dựa trên Highlight.js

3. **Math Rendering**
   - Hiển thị công thức toán học bằng KaTeX

4. **Quota Tracking**
   - Theo dõi RPD / TPM real-time theo model

5. **Pin Conversations**
   - Ghim các hội thoại quan trọng

---

## 🛠️ Công nghệ sử dụng

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **AI API**: Google Gemini 2.5 API
- **Text-to-Speech**: Web Speech API (Microsoft An – vi-VN)
- **Code Highlight**: Highlight.js
- **Math Rendering**: KaTeX
- **Lưu trữ dữ liệu**: localStorage
